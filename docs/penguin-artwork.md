# Penguin ice-path artwork

Created with the built-in imagegen tool for the Grade 1C game. Three original assets, one generation each.
The delivered WebP files preserve the original dimensions and transparent alpha. Encoding compresses the assets for browser delivery; no artwork was redrawn, cropped, or resized.

## penguin

Project asset: `public/1c/art/penguin.webp`

Exact generation prompt:

```text
Use case: stylized-concept
Asset type: transparent game mascot sprite for a children's Chinese-learning website, displayed about 100 px high.
Primary request: Create one single adorable original cartoon penguin standing upright, facing slightly right but mostly front. Navy-black rounded body, bright white belly and face, orange beak and feet, large friendly eyes, and small flippers spread as if ready to hop.
Scene/backdrop: Genuinely transparent background with real alpha, no painted checkerboard and no solid backdrop.
Style/medium: Polished playful children's game art, soft 2.5D shading, simple bold rounded silhouettes, clean readable forms, sunny welcoming polar adventure. An independent original mascot.
Composition/framing: Square 1024x1024 image. Entire character visible, centered with safe clear margins; feet near the bottom. Keep forms readable at 100 px high.
Constraints: Exactly one penguin. No props, no text, no letters, no icons, no logo, no watermark. No scenery or external cast shadow baked outside the character. Not a branded Duolingo owl or logo. Preserve actual transparent alpha around the whole character.
```

## ice-floe

Project asset: `public/1c/art/ice-block.webp`

Exact generation prompt:

```text
Use case: stylized-concept
Asset type: transparent reusable stepping-stone game platform for a children's Chinese-learning website, displayed about 160x100 CSS pixels.
Primary request: Create one single chunky floating ice block or ice floe in a gentle three-quarter overhead/isometric view. It has a broad snow-white flat top, an irregular rounded polygon edge, thick translucent light-cyan beveled sides, and a little reflected turquoise along the underside.
Scene/backdrop: Genuinely transparent background with real alpha, no painted checkerboard and no solid backdrop.
Style/medium: Polished playful children's game art, soft 2.5D shading, simple bold rounded silhouettes, clean readable forms, sunny welcoming polar adventure.
Composition/framing: Square 1024x1024 image containing a wide landscape-ish block centered with safe margins. Wide enough for a small penguin to stand on later; its top is completely empty.
Constraints: Exactly one ice block. No penguin, no animals, no water, no letters, no icons, no numbers, no scenery, no logos, no watermark. No detached cast shadow outside the block. Preserve actual transparent alpha around the entire block.
```

## polar-water

Project asset: `public/1c/art/polar-water.webp`

Exact generation prompt:

```text
Use case: stylized-concept
Asset type: portrait polar seawater background for a vertical children's Chinese-learning path; five stepping-stone ice blocks will be overlaid later.
Primary request: Illustrate open polar seawater viewed from above at a gentle three-quarter overhead angle. Friendly bright turquoise and deep teal blue water, soft hand-drawn curving ripples, and subtle sparkles. A few distant small ice fragments only at the extreme outer edges.
Style/medium: Polished playful children's game art, soft 2.5D shading, simple bold rounded shapes, clean readable forms, sunny welcoming polar adventure.
Composition/framing: Portrait 1024x1536 image, edge-to-edge opaque water. Generous clear uninterrupted central area throughout the height for five overlaid stepping-stone ice blocks. Water fills the frame; no sky or horizon.
Constraints: No characters, no full ice blocks or platforms in the center, no land, no sky, no horizon, no text, no letters, no icons, no numbers, no UI, no logos, no watermark. The center must remain clear and visually calm.
```
